示例视频均裁切、调色、重构图，并去掉音轨。人像底图由照片移位和调色制作，Pexels 条目依 [Pexels License](https://www.pexels.com/license/) 使用。金线和波纹由代码绘制。Segoe Script 取自 Windows 本机字体，项目只提供字体路径。

如需从原始素材重建示例，将上述 Pexels 视频保存为其数字编号加 `.mp4`，照片保存为 `11889790.jpg`，赛事视频保存为 `beam.webm`，然后执行 `python prepare_demo.py 源文件目录 assets pip`。
