# 晚点 LatePost 竖屏候选实施分工

从复核后的 71 段中选择 64 段制作独立竖屏模板。其余 7 段依赖专属场景演出。此表记录实施范围和分工。

所有候选使用独立竖屏标签。对照原片抽帧和实际 Remotion 输出，验证构图、进出场动作、文字字位和素材类型。媒体槽按原片要求接受真实图片或连续视频。博主 Logo、角标与原平台水印全部移除，原字标位置显示背景。业务主体图标仍作为可替换的内容素材。

参照画面中无法独立取得的现场镜头使用同类型连续素材，例如工资单和回本公式的车间背景。部分原字幕覆盖区和标识边缘经过局部修补。字体按固定字位用对应风格字形重建。图表正式调用使用可核验数据，个别预览为版式对照而量取原屏幕数据。桑基图预览采用 GCAP 数据，示例显示 63%，参考画面显示 74%。
