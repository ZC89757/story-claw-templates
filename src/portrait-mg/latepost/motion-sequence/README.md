两个组件沿用原字幕位置的背景空白，由宿主绘制口播字幕。

`globe-tracking.json` 的每一行对应底片的一帧。三个三元组依次为左上、左下、右下价签文字的中心 x、中心 y 和可见透明度，设计坐标为 360×640。

`workHoursContract.media` 请求从 `background.sourceStart` 起覆盖整段时长的实际视频。数字的 `at` 在 Provider 调用参数中是绝对秒，组件接收已转换的片内时间。
