# LatePost 三条独立竖屏模板

从 `contracts.ts` 取得 `mapTransferContracts`，从 `index.tsx` 取得 `mapTransferBatch`。三条组件均以 360×640 的竖屏坐标绘制，模板外层使用 `PortraitCanvas`。以 30 fps 源时间锁定镜头动作速度。旁白字幕由宿主绘制。

| 条目 | 参考片 | 宿主时间窗 | 示例素材和画面差异 |
| --- | --- | --- | --- |
| V06_002 地图标注供货商 | BV18ZeB62Eas，111.580–128.690 秒 | 15.2–17.1 秒 | 三个厂点和产品全部出现后可收镜。上限对应 513 帧连续底片。从原镜头逐帧分离地图，对遮挡位置用几何配准后的相邻帧修补，县域近景的局部灰阶仍有拼接痕迹。五瓶各自抠成透明 PNG。 |
| V07_004 教师到学生的数据传递 | BV1jchK6REaB，62.433–73.633 秒 | 10–11.2 秒 | 第 251 帧起播放同一镜头的连续粒子素材，前 14 帧保留两侧可干净分离的光点。上限对应素材结束，最短窗口保留超过一秒的全幅粒子传输。光管周围局部亮度与原片有差异。节点、表格、红箭头和色差闪切由组件重建。 |
| V07_005 等轴技术扩散图 | BV1jchK6REaB，145.300–161.767 秒 | 至少 14.7 秒 | 较短窗口提前开始末段淡出，较长窗口保留拉远后的最终图形。七枚模型标识逐枚抠成透明 PNG。三段等轴运镜、投影文字、立牌与方块用组件重建。字体以 SimSun 系列重建，投影角度和阴影为近似值。 |

底片为无声连续 H.264 视频。主图标、厂名及样例文字均是独立可替换元素。片头博主标识、两侧栏目角标和平台水印已从素材和组件画面去除。统一预览和目录注册由主对话接入。
