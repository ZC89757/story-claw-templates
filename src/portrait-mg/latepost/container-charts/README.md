# 容器图表竖屏模板

导入 `contracts.ts` 的 `containerChartContracts` 取得纯契约，导入 `index.tsx` 的 `containerChartBatch` 取得正式组件与示例。契约时间字段 `at` 使用绝对秒，组件示例中的 `at` 使用相对秒。底部保留原有留白，口播字幕由宿主渲染。

| 条目 | 只读参考 | 图层和素材 |
| --- | --- | --- |
| V04_001 双色气泡对照 | BV1WAJy6mE4y，30.867–38.067 秒 | 原灰阶底为静态层。标题、来源、标签、虚线、实心圆、半透明圆及连接带由组件绘制。 |
| V06_001 瓶身液位对比 | BV18ZeB62Eas，65.280–73.300 秒 | 原灰阶底与双层货架为静态层。瓶身、红液材质和七枚用于图表标识的零售商图标都是 RGBA PNG，来自该参考片段 3.000 秒和 4.533 秒的局部轮廓。液位和数字由组件分组驱动。 |

参考左上角的平台水印及顶部两处博主标识原位露出灰阶背景。瓶身下缘被品牌标识挡住的极小区域用同一瓶身纹理接续，红液纹理向瓶颈延伸以支持超过示例 90% 的数值。细字和图表数字采用系统字体，按参考字宽、字重与字位重建。
